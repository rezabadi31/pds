# PDS_GUI (Legacy Directory)

This directory is preserved for backwards compatibility with previous Streamlit Community Cloud deployment settings.

The master application has been redesigned and relocated to the project root:
- Main file: `../app.py`
- Main config: `../config.py`
- Components: `../components/`
- Views: `../views/`
- Utilities: `../utils/`

To launch the dashboard, execute from the repository root:
```powershell
streamlit run app.py
```
