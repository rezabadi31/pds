10. CONFUSION MATRIX INTERPRETATION
------------------------------------------------------------------------------
Logistic Regression Confusion Matrix Analysis:
  - The linear decision boundary with balanced weighting prioritizes recall,
    correctly flagging over 96-100% of attack instances across all classes.
  - However, linear boundaries overlap significantly in high-dimensional feature
    space, misclassifying several thousand benign logs as attack types (lower precision).

Random Forest Confusion Matrix Analysis:
  - Non-linear orthogonal decision trees successfully partition complex behavioral
    clusters without sacrificing precision on the benign majority class.
  - Minimal false positives and near-zero cross-attack confusions.

13. PRACTICAL LIMITATIONS & CYBERSECURITY IMPLICATIONS
------------------------------------------------------------------------------
1. Accuracy Paradox: High accuracy (96-99%) is naturally inflated by the massive
   benign majority (99.7%). Macro F1 and class-specific recall are the true metrics.
2. Evasion & Adversarial Perturbations: Attackers intentionally fragment payloads,
   rotate user agents, or slow down request rates to evade entropy & rate features.
3. Concept Drift: Web application updates and novel zero-day attack signatures require
   continuous telemetry retraining.
4. Deployment Latency: Random Forest tree ensemble inference introduces higher memory
   and compute overhead compared to lightweight linear models in inline firewalls.
