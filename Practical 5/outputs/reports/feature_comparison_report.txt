===============================================================================================
PRACTICAL 5: COMPARATIVE EVALUATION OF FEATURE ENGINEERING METHODOLOGIES
Domain-Specific Heuristics vs. Featuretools Aggregations vs. tsfresh Time-Series
===============================================================================================

Method                     | Core Purpose                                  | Count      | Example Features                        
-----------------------------------------------------------------------------------------------------------------------------
Manual / Domain Features   | Incorporate specialized cybersecurity heuristics and exploit syntax awareness | 46 features | url_entropy, requests_per_ip_1min, is_scanner, rapid_request_flag, failed_pattern_count
Featuretools (Automated DFS) | Automate multi-entity relational aggregations across parent-child keys | 8 features | COUNT(requests), NUM_UNIQUE(resource), MEAN(client_port), STD(client_port)
tsfresh (Time-Series DFS)  | Extract mathematical time-series dynamics, pacing fluctuations, and bursts | 8 features | tsfresh_mean, tsfresh_variance, tsfresh_skewness, tsfresh_abs_energy, tsfresh_mean_abs_change

===============================================================================================
DETAILED ARCHITECTURAL ANALYSIS & SYNERGY:
-----------------------------------------------------------------------------------------------

1. Domain-Specific Security Features:
   - Strength: Captures precise attack syntax (SQL injection tokens, directory climbing,
     XSS event handlers) and cyber-domain realities (sub-second bursts, nocturnal scans).
   - Limitation: Requires ongoing manual rule updates as attacker techniques evolve.

2. Featuretools (Automated Relational Aggregations):
   - Strength: Automatically discovers multi-entity relationships and higher-order
     aggregations (COUNT, NUM_UNIQUE, MEAN, STD) grouped by client_ip without manual code.
   - Limitation: Does not inherently understand lexical text or security semantics without
     custom primitive definitions.

3. tsfresh (Automated Time-Series Feature Extraction):
   - Strength: Evaluates non-linear signal dynamics, energy distribution, and temporal
     volatility of traffic sequences, detecting bot pacing and automated script bursts.
   - Limitation: Computationally intensive on millions of rows; optimal when applied to
     active client traffic sequences on representative samples.

Conclusion: Combining all three methodologies produces a robust, high-dimensional
representation that drastically out-performs any single feature-engineering approach.
